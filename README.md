# JOSENGA One-Company OS

AI-powered operating system for a one-person company: Command Center, Leads & Sales, Clients, Jobs, Invoices & Cash, Marketing, and AI Business Advisor.

## Revenue model
- Starter: $99/month
- Growth: $299/month
- Business: $999–$2,000/month
- Pilot implementation target: $1,500 setup + $500/month

## Core flow
Lead → Quote → Job → Invoice → Payment → Reconcile → Profit

## AI operating rule
AI prepares and verifies. Owner approves sensitive actions. The system records the decision and result.

## Current release
Static-first MVP with browser-local data storage and a ChatGPT handoff workflow. No API keys are stored in the client.
